## CYPERPUP (CPHP) Token - CypherPunk Hackathon Project

- The CypherPup (CPHP) token is an ERC20-compliant token with additional features such as minting, fee redistribution, burning, and pause functionality. It integrates access control using roles and allows token distribution across multiple wallets. It also supports a whitelist and anti-whale mechanisms to manage the token distribution and transfer limits

## TOOLS

Chain - Cypherium and Sepolia Testnet
TOOLS - VScode, Foundry( Forge, Cast, Anvil, Chisel)
Rference - https://book.getfoundry.sh/

### Project Setup and Configuration

1. Install the Foundry CLI
2. Git clone the repository `git clone git@github.com:Enockkipkoech/cypherium-cphp-coin.git `
3. Run the following commands to install the dependencies and build the project

```shell
$ forge build
$ forge test
$ forge fmt
$ forge snapshot
$ anvil
$ forge script script/Counter.s.sol:CounterScript --rpc-url <your_rpc_url> --private-key <your_private_key>
$ cast <subcommand>
$ forge --help
$ anvil --help
$ cast --help
```
